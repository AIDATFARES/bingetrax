# BINGETRAX IPTV

Official website and web platform for **BINGETRAX IPTV** — Premium 4K IPTV Subscription Service.

- **Production Domain**: [www.bingetrax.top](https://www.bingetrax.top)
- **Repository**: [https://github.com/AIDATFARES/bingetrax.git](https://github.com/AIDATFARES/bingetrax.git)

---

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **React**: 19
- **Styling**: Tailwind CSS v4 & Lucide Icons
- **Animations**: Framer Motion

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Build for Production

```bash
npm run build
npm run start
```
